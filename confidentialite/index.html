Politique de confidentialité

Dernière mise à jour : 27/11/2026.

Cette page explique quelles données le compte Instagram @akyuro.ia et ce site traitent, pourquoi, combien de temps, et comment exercer vos droits (règlement européen sur la protection des données, RGPD).

Ce site

Ce site est un ensemble de pages statiques hébergées par GitHub Pages. Il n'utilise ni cookie, ni outil de mesure d'audience, ni publicité, ni police ou script tiers. GitHub, l'hébergeur, peut enregistrer des données techniques de connexion (comme l'adresse IP) pour la sécurité de son service : voir la politique de confidentialité de GitHub.

Instagram : commentaires et messages privés

Quand vous commentez le mot-clé d'une vidéo (par exemple « BOUTIQUE »), nous vous répondons pour vous donner le guide demandé. Pour cela, nous traitons seulement :

  • votre nom d'utilisateur Instagram (et l'identifiant technique fourni par Instagram) ;
  • le texte de votre commentaire ou de votre message (pour reconnaître le mot-clé) ;
  • la date, et la vidéo concernée.

Finalité : vous envoyer le guide demandé (réponse sous votre commentaire et, si vous le permettez, un message privé avec le lien), une seule fois par vidéo. Base légale : votre demande (vous avez commenté le mot-clé).

Durée de conservation : 90 jours pour les commentaires et les messages, puis effacement automatique.

Plus tard, si vous vous inscrivez à la lettre d'information (inscription volontaire, avec confirmation par e-mail) : votre adresse e-mail, utilisée seulement pour vous envoyer les nouveaux guides, jusqu'à votre désinscription (un lien dans chaque e-mail).

Aucune revente : vos données ne sont ni vendues, ni louées, ni utilisées pour de la publicité. Elles ne sont transmises qu'aux prestataires techniques nécessaires : Meta (Instagram), Zernio (envoi des messages privés) et GitHub (hébergement de ce site).

Ne plus recevoir de message

Répondez « stop » en message privé : vous ne recevrez plus de message automatique.

Vos droits

Vous pouvez demander l'accès à vos données, leur rectification ou leur suppression, et vous opposer à leur traitement, en message privé sur Instagram à @akyuro.ia. Réponse sous 30 jours. Vous pouvez aussi déposer une réclamation auprès de la CNIL (cnil.fr).

Pour faire supprimer vos données : page « Suppression des données ».
