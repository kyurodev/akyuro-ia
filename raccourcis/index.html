5 raccourcis Claude Code pour arrêter de tout retaper

Guide du reel « 5 raccourcis Claude Code » · mis à jour le 27/11/2026

Tu perds du temps à cliquer partout ou à retaper tes prompts dans le terminal de Claude Code ? Voici 4 réflexes clavier et un bonus.

Ce qu'il te faut

  • Claude Code ouvert dans ton terminal, en mode interactif.
  • Un éditeur de texte par défaut configuré sur ta machine (pour le raccourci Ctrl+G).

Étapes

  1. Esc : coupe la réponse en cours. Claude part dans la mauvaise direction ? Appuie sur Esc. La réponse ou l'action en cours s'arrête, et Claude garde le travail déjà fait. Tu peux alors le réorienter sans repartir de zéro.
  2. Ctrl+G : écris ton prompt dans ton éditeur. Pour un long prompt, appuie sur Ctrl+G. Ton prompt s'ouvre dans ton éditeur de texte par défaut, où tu peux le rédiger et le modifier plus confortablement.
  3. Shift+Tab : change de mode de permission. Appuie sur Shift+Tab pour faire défiler les modes de permission sans ouvrir de menu : default (affiché « Manual » dans l'indicateur de mode), puis acceptEdits, puis plan. D'autres modes peuvent suivre s'ils sont disponibles chez toi.
  4. Option+P / Alt+P : change de modèle. Appuie sur Option+P (ou Alt+P, selon ton clavier) pour passer à un autre modèle sans effacer le prompt que tu es en train d'écrire.
  5. Bonus, Ctrl+S : mets ton brouillon de côté. Tu as commencé un prompt mais tu veux d'abord poser une autre question ? Appuie sur Ctrl+S : ton texte est mis de côté et la zone de saisie est vidée. Une fois le prompt vide, appuie de nouveau sur Ctrl+S pour retrouver ton brouillon.

Bon à savoir

  • Avec Esc, tu ne perds rien : Claude garde le travail déjà fait, ce qui te permet de corriger le tir en cours de route.
  • Ctrl+G fonctionne aussi quand tu dois écrire une réponse personnalisée, pas seulement pour ton prompt.
  • Le second appui sur Ctrl+S ne restaure ton brouillon que si la zone de saisie est vide. Il récupère alors le texte, la position du curseur, le contenu collé et le mode de saisie.
  • Les modes proposés par Shift+Tab au-delà de default, acceptEdits et plan dépendent de ce qui est disponible dans ta configuration.
