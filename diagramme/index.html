Transformer ton plan de projet en diagramme interactif avec Archify

Guide du reel « Trois pages de plan en un diagramme » · mis à jour le 25/11/2026

Tu as un plan de projet long et difficile à présenter ? Voici comment utiliser Archify avec Claude Code pour en faire un diagramme interactif.

Ce qu'il te faut

  • Claude Code, installé et accessible selon ton offre (la fiche ne précise pas les offres concernées).
  • Le texte de ton plan de projet, prêt à être copié.
  • Un peu de temps pour lire les instructions du dépôt Archify.

Étapes

  1. Ouvre le dépôt Archify. Va sur https://github.com/tt-a1i/archify. Archify est un outil tiers, pas d'Anthropic. Le dépôt le présente ainsi : « Turn any idea, plan, or codebase into a beautiful interactive diagram. An agent skill for Claude Code, Codex, and more. » Autrement dit, c'est un skill qui transforme une idée, un plan ou du code en diagramme interactif.
  2. Installe le skill. Suis les instructions d'installation indiquées dans le dépôt lui-même. Elles peuvent évoluer, alors fie-toi à ce qui y est écrit au moment où tu le fais, plutôt qu'à une commande copiée ailleurs.
  3. Ouvre Claude Code et colle ton plan. Lance Claude Code, puis colle le texte de ton plan de projet, même s'il est en vrac.
  4. Demande un diagramme avec Archify. Écris simplement à Claude de transformer ton plan en diagramme avec Archify. Le skill se charge de construire le schéma à partir de ton texte.
  5. Clique sur chaque bloc et relis. Le diagramme est interactif : parcours chaque bloc, vérifie que rien ne manque et que chaque élément correspond bien à ce que tu voulais dire. Corrige ou redemande des ajustements si besoin, avant de présenter.

Bon à savoir

  • Archify est un outil tiers, pas d'Anthropic : prends le temps de lire le dépôt avant de l'installer, comme pour tout outil externe.
  • Le dépôt est publié sous licence Apache-2.0.
  • Le skill fonctionne avec Claude Code, mais aussi avec d'autres agents comme Codex, d'après la description du dépôt.
  • Un diagramme généré reste une proposition : c'est ta relecture qui le rend fiable pour ta présentation.
