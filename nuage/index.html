Ordi fermé, code réparé : lancer Claude Code dans le cloud

Guide du reel « Ordi fermé, code réparé » · mis à jour le 23/11/2026

Maintenant, Claude peut continuer à travailler sur ton code dans le cloud pendant que ton ordinateur est fermé. Voici comment lancer une tâche, partir, puis la suivre depuis ton téléphone.

Ce qu'il te faut

  • Une offre qui donne accès aux sessions cloud : Pro, Max, Ultra ou Team. Avec Enterprise, il te faut un siège premium ou un siège Chat + Claude Code.
  • Le projet de code sur lequel tu veux que Claude travaille.
  • Un navigateur pour ouvrir claude.ai/code, ou ton terminal si tu préfères lancer la tâche en ligne de commande.
  • Si tu veux suivre la session depuis ton téléphone, l'app Claude.

Étapes

  1. Vérifie ton offre. Les sessions cloud sont disponibles avec Pro, Max, Ultra et Team. Avec Enterprise, elles demandent un siège premium ou un siège Chat + Claude Code. Si tu n'es pas sûr de ton offre, commence par là.
  2. Lance ta tâche. Dans ton navigateur, ouvre claude.ai/code, aussi appelé Claude Code sur le web, et décris ce que Claude doit faire. Tu peux aussi lancer la tâche depuis ton terminal avec claude --cloud suivi de ta demande, par exemple : claude --cloud "Fix the authentication bug in src/auth/login.ts"
  3. Ferme ton ordinateur. La session continue de tourner dans le cloud, même ordinateur fermé. Tu peux partir.
  4. Suis ou pilote la session depuis n'importe quel appareil. Sur ton téléphone, ouvre l'onglet Code de l'app Claude. Tu peux y voir où en est la session et la réorienter si besoin.
  5. Récupère le résultat à la fin. Quand la session est terminée, deux choix s'offrent à toi : créer la pull request depuis claude.ai/code, ou rapatrier la session dans ton terminal avec claude --teleport pour continuer à travailler dessus.

Bon à savoir

  • Les sessions cloud comptent dans les limites d'utilisation de ton offre. La machine virtuelle dans le cloud n'est pas facturée à part.
  • Chaque commande --cloud crée sa propre session cloud, qui tourne indépendamment des autres. Tu peux donc lancer plusieurs tâches séparées.
  • Le nom à retenir dans le navigateur est claude.ai/code. Sur mobile, c'est l'onglet Code de l'app Claude.
