Fini le copier-coller des tarifs fournisseur

Guide du reel « Fini le copier-coller des tarifs » · mis à jour le 25/11/2026

Merci pour ton commentaire. Voici comment récupérer les tarifs de nombreuses pages d'un fournisseur avec Crawl4AI, puis demander à Claude de les ranger dans un seul tableau, au lieu de tout recopier à la main.

Avant de commencer : Crawl4AI est un outil tiers, pas d'Anthropic. Ce guide le présente, mais ne remplace pas sa documentation.

Ce qu'il te faut

  • La liste des pages de tarifs de ton fournisseur (leurs adresses web).
  • Un accès à Crawl4AI. Deux possibilités : la version hébergée, Crawl4AI Cloud, ou le code du dépôt que tu installes toi-même.
  • Un accès à Claude, selon ton offre.
  • Un peu d'aisance technique. Cette astuce s'adresse plutôt à un public avancé.

Étapes

  1. Rassemble tes pages. Note dans une liste toutes les adresses des pages de tarifs que tu recopies habituellement. C'est la base de tout le reste.
  2. Choisis ta façon d'utiliser Crawl4AI. D'après la page du dépôt, Crawl4AI Cloud est une API hébergée d'extraction, de récupération et de recherche web, pensée pour les agents IA. Tu peux aussi héberger toi-même l'outil : le dépôt contient le code open source qui fait tourner la version hébergée.
  3. Prépare ton accès. Pour la version hébergée, la page du dépôt indique une clé API gratuite. Pour l'auto-hébergement, suis les instructions du dépôt. Ce guide ne détaille pas les commandes, car la fiche sur laquelle il s'appuie ne les donne pas.
  4. Lance l'extraction sur tes pages. Utilise Crawl4AI pour récupérer le contenu de chaque page de ta liste, en suivant la documentation du dépôt.
  5. Confie le résultat à Claude. Transmets le texte extrait à Claude, par exemple en le collant dans la conversation. Demande-lui de ranger les prix dans un tableau, avec par exemple une ligne par produit et des colonnes pour la référence, le nom et le prix.
  6. Vérifie avant d'utiliser. Compare quelques lignes du tableau avec les pages d'origine pour t'assurer que les prix sont bien repris. Garde ce réflexe à chaque mise à jour.

Bon à savoir

  • L'offre gratuite. Selon la page du dépôt, vérifiée le 24 novembre 2026, la version hébergée propose une clé API gratuite, 1 000 crédits par mois et aucune carte bancaire. La page ne précise pas combien de crédits consomme une page. Vérifie ce point sur le dépôt avant de lancer beaucoup de pages.
  • Open source. Le dépôt est sous licence Apache-2.0. Si tu préfères ne pas dépendre de la version hébergée, tu peux héberger l'outil toi-même.
  • Le droit d'utiliser ces pages. Vérifie que les conditions du site de ton fournisseur t'autorisent à récupérer ses pages de cette façon.
  • Ce qui évolue. Les conditions de Crawl4AI peuvent changer. Consulte le dépôt pour connaître les modalités en vigueur.
